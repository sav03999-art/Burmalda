# ЛАГРАНЖ · Эпизод I

Космический экшен в браузере. Один файл `index.html`, Three.js, вся графика и звук генерируются процедурно при загрузке.

- Планета с атмосферой, облаками и огнями городов, луна, Млечный Путь
- Станция «Гелиос-3», истребитель «Стриж», пираты, пояс астероидов
- 5 сюжетных миссий, вступительный ролик, стыковка, свободный полёт с волнами пиратов
- Управление с ПК (мышь + клавиатура) и с телефона (сенсорные кнопки)

## Запуск

Откройте `index.html` в браузере или включите GitHub Pages (Settings → Pages → ветка `main`, папка `/`).
Нужен интернет: движок Three.js и шрифты грузятся с CDN.
